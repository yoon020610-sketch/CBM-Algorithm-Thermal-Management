# CBM Early-Warning Algorithm for Ram-Air Heat Exchanger
This repository contains the Python source code and experimental data for the paper: 
"A Scaled-Down CPU Cooler Study on Fin Fouling Effects on the Transient Thermal Response of a Ram-Air Heat Exchanger and a Temperature-Rate-Based Condition-Based Maintenance Algorithm"

## Files
- `cbm_algorithm.py`: 핵심 조기 경보 알고리즘 파이썬 코드
- `gu05.csv`: 실험 온도 데이터셋 (거즈 5겹 가혹 조건)
